# docs/ — Documentation & Deliverables

## Subdirectories

| Folder | Contents | When to use |
|--------|----------|-------------|
| `user-manuals/` | 14 polished Word (.docx) user manuals for specific Odoo modules | When writing, updating, or referencing an existing user guide |
| `blogs/` | Blog posts written for infintor.com (Odoo 19 how-to format) | When drafting a new blog or referencing a past one |
| `guides/` | Writing style guide, SEO reference | Check before writing any blog or doc |
| `comparison/` | Odoo vs. traditional ERP comparison document | Business justification / sales support |
| `media/` | Screenshots and reference PDFs | Visual evidence for docs and blogs |
